# 🎬 CineBase — каталог фильмов

Одностраничное приложение на **React + Vite** (Midterm Project — React SPA).
Каталог из 110 фильмов с поиском, фильтрацией, сортировкой, пагинацией, страницей деталей и формой добавления нового фильма.

**Деплой:** _вставьте ссылку на Vercel/Netlify_

## Возможности

- Список фильмов (карточки) и страница деталей отдельного фильма
- Поиск по названию и режиссёру (с debounce 400 мс)
- Фильтр по жанру и 6 вариантов сортировки
- Пагинация (12 фильмов на странице)
- Управляемая форма добавления фильма с валидацией
- Удаление фильма, сброс данных к исходным
- Состояния **loading / error / empty / success**
- Переключатель «Симулировать ошибку API» для проверки состояния ошибки
- Адаптивная вёрстка (десктоп и мобильные)

## Источник данных

Симулированный API (`src/api/fakeApi.js`):

- 110 исходных записей (`src/data/movies.js`)
- Promise + случайная задержка 400–900 мс
- Данные хранятся в `localStorage` (добавленные и удалённые фильмы сохраняются после перезагрузки)
- Поиск, фильтрация, сортировка и пагинация выполняются «на стороне API», как на настоящем сервере
- Поддержка отмены запроса через `AbortController`

## Технологии

React 18 (хуки `useState`, `useEffect`), Vite 5, чистый CSS. Без UI-библиотек и без прямой работы с DOM.

## Структура проекта

```
src/
├── api/fakeApi.js          # симулированный API
├── data/movies.js          # 110 исходных записей, список жанров
├── hooks/useDebounce.js    # хук для отложенного поиска
├── components/
│   ├── MovieList.jsx       # список карточек
│   ├── MovieCard.jsx       # карточка фильма
│   ├── MovieDetail.jsx     # страница деталей
│   ├── AddMovieForm.jsx    # управляемая форма
│   ├── SearchBar.jsx       # поиск
│   ├── Filters.jsx         # жанр + сортировка
│   ├── Pagination.jsx      # пагинация
│   ├── Poster.jsx          # постер-заглушка
│   ├── Loader.jsx          # состояние загрузки
│   ├── ErrorMessage.jsx    # состояние ошибки
│   └── EmptyState.jsx      # пустой результат
├── App.jsx                 # состояние и загрузка данных
├── main.jsx                # точка входа
└── styles.css              # стили
```

## Запуск локально

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:5173

Сборка для продакшена: `npm run build`, предпросмотр: `npm run preview`.
